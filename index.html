SMRTTECH Lab ZIP Reader

Open exported lab submission ZIP packages or standalone completion JSON files, inspect their contents, and generate grading reports.

Local processing

This tool runs locally in your browser. Uploaded completion files are not sent to a server by this page.

Integrity context

Client-side export hashes help detect changes after export but do not make a file tamper-proof.
